Hands Off Kit: AI Agent Governance & Codebase Control Layer

Flagship Project

AI coding agents can rapidly generate and modify source code. However, unrestricted access to a codebase can result in unintended regressions, overwriting of tested modules, and weak enforcement of architectural rules. Hands Off Kit acts as a strict control layer between AI agents and production code by combining task tracking, protected files, isolated Git worktrees, change detection, authorization checks, and human review gates.

Key Security & Control Capabilities:

  • Protected Files & Rule Engine: Prevents AI agents from overwriting mission-critical modules (e.g. .env, authentication, database migrations).
  • Isolated Git Worktrees: Sandboxes agent operations within isolated Git worktrees, preserving developer workspace stability.
  • Task Tracking & Scope Bounds: Restricts agent read/write permissions strictly to declared task tickets and authorized subdirectories.
  • Change Detection & AST Diffs: Employs syntax tree parsing to catch regressions, breaking interfaces, and architectural rule violations.
  • Human Review Gates: Enforces interactive authorization checkpoints before any AI-generated diff merges into production branches.
